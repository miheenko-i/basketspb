# BASKETSPB

Редизайн школы баскетбола и фристайла в Санкт-Петербурге.

Сайт: https://miheenko-i.github.io/basketspb/

## Разработка

Node.js 22.13 или новее.

```sh
npm ci
npm run dev
```

Локальный адрес: http://localhost:3000/basketspb/

## Публикация

```sh
npm run build
```

Статический сайт создаётся в `dist/client`. GitHub Actions автоматически собирает и публикует ветку `main` через GitHub Pages. Базовый путь `/basketspb` задан в `next.config.ts`.

## Содержание

Тексты, расписание и фотографии перенесены с https://basketspb.ru/ 9 сентября 2026 года. Расписание относится к сезону 2026/27. Указанные на исходном сайте цены относятся к сезону 2025/26; эта пометка сохранена. Экономия по абонементу на 8 занятий рассчитана относительно восьми разовых занятий: 8 × 1 200 − 7 200 = 2 400 ₽ (25%).

Запись открывает Telegram администратора с подготовленным текстом. Персональные данные не сохраняются на сайте. Приложение не подтверждает запись автоматически.

Видео предоставлено пользователем, оптимизировано для фонового воспроизведения; звуковая дорожка удалена. Видео останавливается при включённой настройке уменьшения движения. Шрифты размещены локально.

## Проверки

Сборка, проверка TypeScript и HTTP-проверки статических ресурсов. Дополнительный WebMCP-интерфейс `show_training_schedule` использует те же настройки расписания; полноценная проверка контракта требует браузера с WebMCP.
